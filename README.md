# test

Тестовий репозиторій для демонстрації роботи Claude Code з GitHub.

## Що тут відбулося

1. Claude створив цей файл у хмарному контейнері.
2. Зробив коміт у локальному git.
3. Запушив зміни на GitHub у гілку `claude/github-workflow-ee75pv`.

Без GitHub на кроці 3 все б і закінчилось: після завершення сесії контейнер
видаляється, і зміни зникли б. Завдяки push файл тепер зберігається
в репозиторії і доступний вам та вашій команді.
